# saturn_assets example

Loads the asset overlay for the running Shorebird patch and shows
`assets/message.txt` through the overlaid `DefaultAssetBundle`.

Before building a release, replace the server URL, app ID, release version, and
`pinnedAssetPublicKey` in `lib/main.dart` and `shorebird.yaml` with your Saturn
instance's values. See the
[asset update guide](https://github.com/xirf/saturn-code-push/blob/main/docs/asset-support.md).
