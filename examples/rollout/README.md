# Saturn rollout reference

A minimal Flutter integration using Shorebird's native persistent client ID.
See the [client rollout guide](../../docs/client-rollouts.md) for setup, the verified
upstream source revision, smoke testing, and device acceptance steps.

No Saturn identity plugin, engine fork, or asset package is required.
Generate the Android runner with `flutter create` as documented before building.
This is a reference example; its engine/device flow still requires validation
with your selected Shorebird toolchain.
